# keys

Put `keys.env` here before building to get one-step sign-in for Google Calendar
and Microsoft To Do. Get the file from the project's maintainer, or create your
own from [`keys.env.example`](keys.env.example) (steps in the main README under
*Publishing a release*).

`keys.env` is ignored by git. Without it, everything still builds and works;
users then set up their own Google/Microsoft app inside discommand.
